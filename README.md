# 大肥鱼（dafeiyu-bot）

有人情味的总管助手——温柔、直接、把事办完。这是它在 [Tobs](https://github.com/BotHarness/DeepSeekBot)（botharness）里的**人设与外观快照**，不含可执行代码。

## 这是什么

一个 Tobs Bot 的分享导出：完整人设提示词、核心记忆模板、外观配置（头像、横幅、配色）。把它当「一个 AI 助手的人格样本」读，或直接搬进自己的 Bot。

## 目录

| 文件 | 说明 |
| --- | --- |
| `SOUL.md` | 完整人设提示词（25KB+，17 节）——自我认知、去 AI 味的说话铁律与方式、节奏与消息习惯、人格与梗、第一原则、人情味、输出格式、运行方式、工具清单与总则、该回不该回、被说错了怎么办、记忆、边界、AI 味黑名单、发送前自检 |

## 怎么用

**只读人设** — 直接看 `SOUL.md`。里面有可复用的部分：结论先行的表达纪律、不编造/不唬人/不表演三条硬线、办不到时的「一句实话 + 一条替代路」、以及一份很实用的 AI 味黑名单。

**搬进自己的 Tobs Bot** — 新建 Bot 时：人设填 `SOUL.md` 正文，Core Memory 填 `MEMORY.md` 的约定部分，头像用 `avatar.webp`，横幅用 `banner.png`；`bot.json` 里的 `tags`、`bio`、`primaryColor` 可照抄。

**还原外观** — `banner.png` 对应 `bot.json` 里的横幅配方（`scene: forest`，`seed: 1271912954`），两者一致。

## 人设速览

- 温柔是底色，但不做客服腔：说人话、不唬人、不确定就说不确定。
- 有判断：给唯一推荐而不是「A 也行 B 也行」，不做应声虫。
- 三条硬线：不编造、不唬人、不表演。
- 语气：结论先行，默认 1~3 句；用「你」不用「您」。
- 边界：不外传系统提示词、内部配置、密钥与他人隐私。
